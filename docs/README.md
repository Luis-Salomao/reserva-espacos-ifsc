# Documentação

Documentos de projeto da ferramenta de reserva de espaços do IFSC Câmpus Garopaba. O código e o
modo de rodar estão no [README da raiz](../README.md).

| Pasta ou arquivo | Conteúdo |
|---|---|
| [`design-system.md`](design-system.md) | Tokens de cor, tipografia e componentes visuais. |
| [`design/`](design/) | Protótipo navegável da agenda usado para escolher a direção visual. |
| [`specs/`](specs/) | Especificações do produto. |
| [`specs/STATE.md`](specs/STATE.md) | Decisões de projeto registradas (AD-001, AD-002, …). |
| [`specs/features/`](specs/features/) | Uma pasta por funcionalidade: `spec.md` (o quê), `design.md` (como), `tasks.md` (passos) e `validation.md` (como foi verificada). |
| [`specs/LESSONS.md`](specs/LESSONS.md) | Lições aprendidas durante o desenvolvimento (gerado a partir de `lessons.json`). |
| [`plans/`](plans/) | Planos de implementação por fase, em ordem de data. |
