# Fase 0 — Base do projeto: plano de implementação

**Goal:** Repositório limpo com TanStack Start + Drizzle rodando nos dois alvos (Bun+SQLite e Cloudflare Workers+D1), com todos os gates de qualidade e segurança ativos e os tokens do design system.

**Architecture:** Hexagonal simples (`domain` ← `application` ← `infra`/`web`), imposta por dependency-cruiser. Um schema Drizzle `sqlite-core`; o cliente de banco é escolhido pelo alvo de build via alias de módulo `#db-client`. `DEPLOY_TARGET=local|cloudflare` escolhe Nitro (preset `bun`) ou `@cloudflare/vite-plugin` no `vite.config.ts`.

**Tech Stack:** Bun 1.4.2, TanStack Start (`@tanstack/react-start` ~1.169), React 19, Vite 8, Drizzle ORM 0.45.x + drizzle-kit 0.31.x, `@cloudflare/vite-plugin` + wrangler 4, nitro (`nitro/vite`), `@t3-oss/env-core` + zod 4, Tailwind 4 + shadcn/ui, Biome 2.6, knip, dependency-cruiser, lefthook, Betterleaks 1.9 (instalado via winget), `@lhci/cli`.

**Spec:** `docs/specs/2026-11-01-reserva-espacos-design.md`

## Review Focus

1. Build Cloudflare puxando `bun:sqlite` ou `node:*` sem compat → o bundle do Worker deve ser verificado (`wrangler deploy --dry-run`) sem erro de módulo. Teste: Task 5 passo de dry-run.
2. Variável de ambiente ausente/ inválida em produção → mensagem clara listando a variável, sem imprimir valores. Teste: Task 4 `getEnv` com env inválido.
3. Commit acidental de `.env`/`.dev.vars`/`*.sqlite` → bloqueado por `.gitignore` e Betterleaks. Teste: Task 1 passo que tenta `git add -f` de um segredo falso e o hook rejeita.
4. Tema escuro/claro sem contraste AA nos estados de ocupação → verificado por teste de contraste dos tokens (Task 6).
5. Viewport 360 px com rolagem horizontal → Lighthouse mobile + verificação manual na Task 6.
